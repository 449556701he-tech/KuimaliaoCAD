# 亏麻了 CAD 1.2.3

## 新增与改进

- **批量转换建模 DXF**：可一次选择多张 DWG／DXF，输出 AutoCAD 2018 DXF 到独立目录，原图保持不变。已恢复的天正对象以普通图块、文字和线条写出，便于 Blender、AI 工作流及其他 DXF 工具读取。
- **转换过程可查看**：大图转换放在后台执行，窗口显示当前文件、读取进度和处理阶段；点击停止后，会在当前图纸处理结束后停止后续文件。
- **转换报告**：汇总成功、失败及导入／导出时跳过的对象，便于定位未覆盖的图元。
- **扩展天正对象恢复**：改进部分建筑、结构和设备对象的解析；在样例图纸中验证了房间边界、楼梯、带形窗、幕墙、消防设备实例及相关设备对象。

## 修复

- 修复块扩展记录中反向 XCLIP 边界未正确读取的问题。此前该类裁剪会让 1# 楼梁施工图的二层平面局部构件消失；修复后恢复显示，并保留 DWG／DXF 往返保存中的裁剪范围。
- 修复若干天正对象因版本字段偏移或方向约定差异而未显示的问题，包括部分房间、楼梯、窗和幕墙实例。

## 使用范围

- 天正对象按已实现的对象类型和数据布局支持，尚不是完整的天正解析器；不支持或没有独立显示几何的对象会在报告中标出。
- 建模 DXF 是供外部软件读取的普通 CAD 几何输出，不会保留原对象的天正专有属性。用于工程复核前，请与原始 CAD／天正图纸核对。
