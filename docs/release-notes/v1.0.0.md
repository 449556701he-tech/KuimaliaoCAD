# 亏麻了CAD 1.0.0

1.0 将看图、测量、独立批注和图纸对比串成一套可以复核和交付的流程。精装平面图上的房间测量在模型和布局取得相同读数，天花图实测了按层框选灯带，平面修订图实测了布局差异。

- 测量结果先预览位置，再点击放置。对齐和线性测量可以指定尺寸线位置。面积闭合后还能添加区域或扣除孔洞。
- 画布顶部提示下一步。连续测量预览整个可计入圆弧，显示本段与累计长度，支持在提交前撤回上一段。
- 增加原创测量图标。功能区、悬浮面板和右键菜单共用图标。新建未分类标注默认亮红色，分类色与单条覆盖色在预览和选中时可辨认。
- 顶部直接打开图纸对比，保留首页与文件菜单入口。覆盖范围显示两版可比较图元数，空布局、零差异和筛选无结果分别提示。
- 测量与批注单独保存为 `.mcnotes`，统计和图纸对比支持 UTF-8 CSV。Windows x64 安装包增加「D3D11 兼容启动」，macOS Apple Silicon 使用 Metal。
