# 亏麻了CAD（LCQCAD）1.0.2

LCQ 代表 Loss（亏损）、Cost（成本）、Quantity（工程量）。

- 桌面版自动保存已命名图纸的测量结果到本机用户数据目录。再次打开原路径、相同内容的图纸时自动恢复。
- 「另存为当前测量文件」导出可随 DWG 一起交接的 `.mcnotes`。下载到同一文件夹后，软件打开 DWG 会校验并载入同名测量。在本机已有不同结果或图纸被新版覆盖时，用「测量文件」预览并选择采用。
- 新图默认定位到有效图元范围。少量极远图元把范围拉得过大时先定位主体，仍可用「全图」查看完整范围。
- Mac 应用在 Finder 中显示为 LCQCAD。首次启动可选择是否将 DWG、DXF 的默认打开方式交给 LCQCAD；也可右键从「打开方式」单次选择。
- Windows 安装器将 LCQCAD 注册为 DWG、DXF 的候选应用。安装结束可勾选前往系统「默认应用」，分别选择 DWG 和 DXF 的处理程序。

1.0 系列同时包含 1.0.1 的编辑模式和另存为修复。点击「绘图」或「修改」可启用原图编辑，右下角显示「编辑开／关」。图纸另存与测量文件导出各有入口。

macOS 完成 7 组回归及实际大门图开图验证。Windows 安装包使用 x64 Direct3D，已核对包体与版本，默认应用选择流程仍待实机确认。
