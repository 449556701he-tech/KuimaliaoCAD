# 亏麻了CAD 1.0 测量与批注

Windows x64 使用 Direct3D，Apple Silicon Mac 使用 Metal。两版的测量、保存和对比操作相同。安装步骤与第一次测量见[新手指南](../release-notes/v1.0.0-guide.md)。

## 开始使用与保存

1. 打开原 DWG，在底部切到需要的模型或布局。
2. 点击“测量与批注”，选择工具。毫米图纸把“原图模型单位”设为毫米；米图纸设为米。
3. 布局默认自动识别测量视口。存在重叠视口或批量框覆盖多个视口时，在工具窗口明确选择视口，不能混用不同比例。
4. 创建结果后点击“保存独立标注”，或在标注模式按 Command+S。

标注保存在独立 `.mcnotes` 文件中，默认与原图同目录、同主文件名。该保存不会调用 DWG 保存。可直接打开 `.mcnotes`，程序会读取关联原图；原图不在时仍可查看标注快照。搬移图纸时请把两个文件放在一起。

修改原图后，重开标注会提示核对，不会自行挪动标注或重算原有结果。原图另存为时，已有标注转为待保存的新关联，原标注文件保留；如果新位置已有同名标注，程序另选文件名。

“编辑原图”进入原图编辑模式。“选择独立标注”回到标注模式。测量与批注工具会自动进入标注模式；此时绘图、删除、撤销和复制命令作用于独立标注。

## 单位、比例与文字

面积默认显示 ㎡、三位小数，可切换 mm²；长度支持 m、mm。显示精度不改变内部计算。记录保留创建时的原图单位、视口换算和校准参数。

布局自动读取视口比例。例如同一条模型线在 1:5、1:50、1:100 的视口中，工程读数相同。两点校准用于需要额外校正的模型或指定视口：在工具窗口输入已知长度（米），点击“两点校准”，再取两点。新校准作用于后续测量，已有结果需在特性中调整。

“标注设置”控制后续新建记录；选中标注后，在“标注特性”的“分类、颜色与显示项”中修改该条记录。可设置分类颜色或单条颜色、线宽、字号倍率、单位、精度，以及周长、直径、分段标签等显示项。

屏幕文字随窗口和缩放保持可读。导出字高独立保存，单位为当前模型／纸面单位。布局中 3.5 通常表示纸面 3.5mm；模型毫米图在 1:50 导出时，175 的模型字高对应纸面 3.5mm。

## 测量工具

在“测量与批注”的“常用测量”里点“悬浮测量工具”，可直接启动全部 16 项测量（线性分水平、垂直两个按钮）。拖动面板标题移开，画布可同时拾取；再次点入口或点面板 × 关闭。面板底部的“工具与比例设置…”可打开单位、视口和两点校准等设置。点“批量测量”仍先选择图层。

| 工具 | 操作 |
|---|---|
| 对齐 | 点取两点，测实际距离。 |
| 水平／垂直线性 | 分别选择水平或垂直工具，取两点，测指定方向的投影距离。 |
| 矩形面积 | 取两个对角点，显示面积、周长。 |
| 坐标标注 | 点取位置，显示模型 X/Y。参考原点可在标注设置或该条几何特性中设置。 |
| 弧长 | 点选圆弧；多段线中的弧段也可选。按 P 可通过三点定义指定弧段。 |
| 点到直线距离 | 先取测量点，再选直线段；按其无限延长线求垂足与距离。 |
| 连续测量 | 连续捕捉取点；点击原图圆弧中段会计入整段可见弧长，并从另一端继续。离开上一落点的弧段不会自动补直线。A 手动取经过点和终点，L 回到普通点选。悬停显示「本段」和「已计入」，空格或 Backspace 退点。开始取点前按 O 可连续点选原图直线、圆弧或多段线中的单段。回车后进入放置文字。 |
| 批量测量 | 在工具窗口选择原图图层，取框的两个对角点，预览后确认，见下文。 |
| 查看分段长度 | 点选多段线，显示分段编号、各段长度和总长。 |
| 面积（含弧线） | 连续点取直线或弧边；O 选闭合边界，H 扣孔洞，回车完成，见下文。 |
| 测量填充面积 | 点选填充边界或填充内部，读取外边界与孔洞。 |
| 计算侧面积 | 选中已有连续路径或面积记录后启动；也可点取新路径或 O 选原图路径。输入高度，回车完成。 |
| 面积偏移 | 选中已有闭合区域后启动；也可画新边界或 O 选原图闭合边界。输入外扩宽度，回车完成。 |
| 测量圆 | 点选圆，或 P 三点定圆，显示直径、周长、面积。 |
| 半径 | 点选圆、圆弧或多段线弧段；P 可三点定圆。 |
| 测量角度 | 依次取边点、顶点、边点；O 可选两条直线或圆弧，F 切换优角。 |

画布上方显示当前步骤和相关按键。底部命令栏保留操作记录。测量取点或选对象后，右键或回车确认路径；矩形面积点完第二个对角、半径等单对象工具选完对象后会直接进入放置阶段。移动鼠标放好结果文字，再左键确认。对齐和线性标注进入的是指定尺寸线位置。放置阶段按 Backspace 返回取点，Esc 取消整条草稿。完成后标注自动选中，可继续改备注、分类或拖动文字。

### 批量长度

先选图层，再框选。只累计框内且满足图层、显隐、视口冻结及裁剪条件的曲线长度；曲线穿过边框时只计内部部分。不会把双线灯带识别为一条中心线。

预览中有效曲线高亮，点击可以排除／恢复一个来源实例，回车确认框内曲线，再点击放置总长度文字。图块内已解析的曲线、嵌套和阵列实例均可统计；同一实例不会重复计量，不同实例分别统计。无法计量的对象会在命令回显中列出原因与数量。

选中已有批量结果，在特性中点击“重新框选批量测量”可替换该条记录，不会另加一条重复数量。批量来源快照不允许直接修改控制点；重新框选可撤销。

### 含弧面积与孔洞

逐点画外边界时，L 取直线，A 取经过点和终点形成圆弧。按 H 会闭合当前外环并进入扣洞模式；画孔洞后回车进入放置文字，或再按 H 继续扣下一个孔洞。第一次闭合后也能直接按 H 或 C 回到边界操作。按 C 闭合当前环并切回添加区域。O 可选择原图闭合边界；选中已有面积，在特性中点击“添加区域／扣除孔洞”可继续修改同一条结果。

相交或重叠的添加区域合并后计量，孔洞扣除。自交、开放或退化的面积边界会拒绝提交。圆弧参与复杂布尔运算、样条及部分复杂偏移时可能采用数值近似，结果显示“≈”。

### 侧面积与偏移

侧面积为路径长度或闭合边界周长 × 高度。开放路径不自动补最后一条边；本轮不扣门窗洞口。20m × 2.8m = 56.000㎡。可在特性中修改高度。

面积偏移只显示外扩后新增的带状面积。直线角部延长求交，能保留的圆弧使用圆弧；原孔洞不扩，重叠的新增区域合并。10m × 10m 的矩形向外扩 1m，新增 44.000㎡。可在特性中修改宽度。

从已选记录启动侧面积或偏移时，回车使用它的几何；点击图面可改为重画。

## 编辑、批注与分类

标注模式单击选择，Command+单击增减选择，Command+A 选择当前布局可见标注。双击或点击“标注特性”编辑。数值由几何和参数生成，备注可以自由输入中文。

“编辑几何控制点”可调整坐标、圆心、半径、椭圆参数及连续路径的圆弧凸度。凸度 0 为直线、±1 为半圆。点到直线记录的点1为测量点，点2／点3定义参考线，改点后自动重算垂足。矩形编辑保持矩形关系。

移动形状会移动整个形状；移动测量结果只改变文字位置，保留被测几何。Command+C / V 可复制粘贴，Delete 删除，Command+Z 撤销，Command+Shift+Z 重做。跨图纸粘贴保持工程尺寸，清除原来源关联。

直线、矩形、椭圆、引线和文字均在工具窗口中选择。引线、文字在落点后输入内容，确认后生成；取消不会留下空标注。任意线按住鼠标或触控板绘制，松开完成。云线默认两角点矩形，P 切自定义闭合轮廓；云线弧宽可修改。

功能区的分类下拉框可切换当前分类，并将已选标注移入所选分类。“标注分类”窗口支持新建、改名、改色、查找、设为当前、单类显隐和全部显示／隐藏。删除分类只把记录移入“未分类”，不删除记录。“隐藏标注”整体隐藏／恢复批注，不改变原图。

## 统计、查找与导出

“测量统计”默认当前布局，不含隐藏分类；可选整张图纸、包含隐藏分类或指定分类。数量、长度、周长、平面面积、侧面积分开显示。双击明细定位；无效记录显示错误，不作为有效零值累计。导出 UTF-8 CSV 可用 Excel 打开，中文、引号和备注换行保留。

数量指测量记录条数；明细中的来源图元数用于查看该条批量结果包含多少来源实例，不代替灯具等专业对象的数量识别。

“文字查找”搜索原图与新增标注，包含已解析图块内的文字。双击结果或点击定位，跳转到对应布局并高亮。可选择包含隐藏文字；定位不会修改原图或自动打开隐藏图层。

“导出矢量图”生成 SVG，可选当前窗口或完整当前布局／模型，以及原图矢量内容、黑白打印。文字转为轮廓，不依赖接收者安装相同字体；使用导出字高。布局按纸面1:1，模型指定1:N，SVG保存物理毫米尺寸。打印时选择100%／原始尺寸，避免打印软件再次适配纸张。位图图像只导出边框；需要继续编辑标注时保存 `.mcnotes`。

## 兼容范围

旧面积实体继续使用原有保存方式，不自动迁移。若需要复制，在“编辑原图”模式选择旧面积，再点“复制旧面积”，核对原图模型单位后保存独立标注；原对象保留。

测量依赖已解析的二维几何。未解析天正对象仍不保证显示完整或可测；原图缺失字体时可能使用替代字体。本轮不含定距测量、照片、云盘、账号或多人同步。

安装更新不会强制关闭旧窗口。已有窗口请保存后正常退出，再打开 `/Applications/MiniCAD.app` 使用 v5.1。
