# 亏麻了CAD（LCQCAD）

LCQ 代表 Loss（亏损）、Cost（成本）、Quantity（工程量）。

**广联达 CAD 快速看图与 CAD／天正的工程看图、算量和审图替代方案。**

面向造价、施工和图纸复核人员。可以在本机打开 DWG／DXF，核对模型与布局、量取工程量、保存独立批注，也可以叠图检查设计变更。日常看图和算量可用同一个工具完成。天正专有对象的编辑、完整的专业制图和复杂出图仍需使用具备对应能力的 CAD／天正软件。

由大胖爱吃肉（HJX）基于 [开源 MiniCAD](https://github.com/CHMOSE023/MiniCAD) 改版。

### 这一版能做什么

| 工作 | 功能 |
| --- | --- |
| 看图与查找 | 浏览 DWG／DXF 的模型、布局和图层，搜索原图文字、已解析图块内文字与独立批注并定位。可显示一部分天正专有图元，覆盖范围取决于原图数据。 |
| 测量算量 | 对齐、水平及垂直线性、坐标、弧长、点到直线、连续测量、分段长度、按图层批量计长。支持矩形面积、含弧线面积、填充面积、侧面积、面积偏移，以及圆、半径和角度。 |
| 比例与单位 | 布局视口比例、两点校准，长度支持 m／mm，面积默认 ㎡、三位小数，可切换 mm²。 |
| 批注与统计 | 引线、文字、云线、直线、矩形、椭圆和任意线。本机自动保存，支持导出 `.mcnotes` 交接，可按名称或颜色分组，分类显隐，统计导出 CSV，图面可导出 SVG。 |
| 打印与 PDF | A4 至 A0、横竖方向、视觉预览，支持适合纸张、固定比例、矢量 PDF 和系统打印。 |
| 图纸对比 | 旧版与新版 DWG／DXF 叠图、两点对齐、差异筛选与定位、匹配复核和 CSV 导出。 |
| 基础 CAD 编辑 | 切换到「编辑原图」后可用常见二维绘图和编辑功能，例如多段线、移动、复制和图层操作。 |

## 使用说明

### 1. 打开图纸并核对比例

1. 点 **文件 → 打开**，选 DWG 或 DXF。开图优先定位可见图元。底部可切换「模型」或对应布局，要查看远处图元可用「缩放到全图」。
2. 在 **测量与批注 → 常用测量 → 悬浮测量工具** 打开常用工具。点面板底部 **工具与比例设置…**，先设原图模型单位。布局里有多个重叠视口时，明确选择要量的视口。
3. 按 **F3** 打开捕捉。在墙角等位置看到端点提示再点击。候选点重叠时，在画布上按 **Tab** 切换。
4. 先量一段已知尺寸。若 900 mm 的门洞读数仍有偏差，确认单位及视口后，可用 **两点校准**，输入实际长度 **0.9 米**，再取两端。

### 2. 量房间、灯带和墙面

- **矩形面积**。点两个对角，再移动鼠标放置面积文字。4 m × 5 m 的矩形应为 **20.000 ㎡**，周长 **18.000 m**。
- **面积（含弧线）**。沿边界顺序取点，右键或回车闭合。看画布顶部提示，把文字放在需要的位置再点击确认。可按命令提示选取闭合边界、添加区域或扣孔洞。
- **连续测量**。直线按端点逐点取，遇到可识别的圆弧时，点击弧中段可计入整段弧长。也可按 **A** 手动取弧。**空格、Ctrl+Z 或 Backspace** 退点或撤回整段已选圆弧，**回车**确认路径，再点击放置结果，**Esc** 取消。
- **批量测量**。选择灯带等目标图层，再框选范围。复核高亮对象，点击排除或恢复，回车开始放置总长度文字。穿框曲线只计框内部分。双线画法按实际两条曲线分别计长。
- **侧面积和面积偏移**。侧面积按路径长度或周长乘以输入高度，例如 20 m × 2.8 m = **56.000 ㎡**，门窗洞口另行复核。面积偏移显示外扩新增部分，例如 10 m × 10 m 外扩 1 m，新增 **44.000 ㎡**。

### 3. 编辑批注、分类和保存

1. 用 **选择独立标注** 选中结果。直接按住测量文字拖到空白处，松手保存位置。读数和边界保持原样。双击引线文字可编辑，单位、精度和测量参数可在 **标注特性** 调整。
2. 打开 **标注分类**，例如新建「地面」「墙面」「灯带」，给记录分组。打开 **测量统计**，选当前布局或整张图纸，核对明细后导出 **CSV**。长度、周长、平面面积和侧面积分别汇总。
3. 已命名图纸的测量会自动保存在本机。交接时点 **文件 → 另存为当前测量文件**，把同名 `.mcnotes` 和 DWG 放在一起。打开 DWG 时软件会校验图纸内容，有冲突可在「测量文件」里预览。
4. 点击「绘图」或「修改」启用原图编辑。右下角「捕捉」前的「编辑开／关」可手动切换。算量模式下也可以用「另存为图纸」生成 DWG 副本。

### 4. 对比设计变更

1. 点窗口顶部 **图纸对比**，选择磁盘上已保存的旧版和新版 DWG／DXF，再选同一楼层对应的模型或布局。
2. 选 **叠图**。两图位置错开时，点 **两点对齐**，先在旧图选 A、B，再在新版按相同顺序选对应点。优先使用相距较远且两版都保留的轴线交点。
3. 绿色是新增，红色是删除，橙色是修改前，蓝色是修改后。点差异行定位。交付前查看 **覆盖范围** 和 **疑似修改**，然后按当前筛选导出 CSV。

### 5. 打印图纸或导出 PDF

点「文件 → 打印图纸」，选纸张与打印范围。勾选「适合纸张」可以缩放到一页；取消后模型按指定比例、布局按纸面 1:1。预览后导出矢量 PDF 或打开系统打印窗口。位图出图只显示边框。

## 兼容性与当前范围

- 天正门窗、结构板、字体或外参显示有缺失时，先核对图层、布局、字体及外参。关键工程图建议让出图方同时提供转换为普通 CAD 图元的副本，以便复核。
- 当前图纸对比以已解析的可见二维几何和文字为主。覆盖范围显示两侧可比较图元数。遇到空布局提示时，切换有内容的布局；零差异时仍可核对跳过的对象与缺失外参。
- 定距测量、照片批注、云同步和标准 MCP 客户端联调属于当前未交付范围。
